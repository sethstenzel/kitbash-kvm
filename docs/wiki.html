KitBash KVM

A browser and desktop application for controlling a remote computer using a USB capture card and a CH9329-based HID adapter. Stream live video and forward keyboard and mouse input — no software needed on the target machine.

Overview

KitBash KVM works by combining two hardware components:

  • USB Capture Card — captures the target machine's video and audio output and presents it as a webcam to your browser.
  • CH9329 / NanoKVM USB Adapter — receives serial commands from KitBash KVM and emulates a USB keyboard and mouse on the target machine.

Together these let you see and control any machine that has a USB port and a video output, including machines during BIOS, OS installation, or without a network connection.

Getting Started

  1. Connect your USB capture card to the target machine's video output (HDMI, DP, VGA via adapter).
  2. Connect your CH9329 / NanoKVM USB adapter between your computer and a USB port on the target machine.
  3. Open KitBash KVM in your browser or launch the desktop app.
  4. Select your Video device (the capture card) and optionally an Audio device from the action bar dropdowns.
  5. Click the ▶ Play button to start the video stream.
  6. Select your Serial Port (the CH9329/NanoKVM adapter) and the correct Baud Rate.
  7. Click Connect — you are now forwarding keyboard and mouse input to the target.
💡
For a Sipeed NanoKVM USB, use baud rate 57600. For a standard CH9329 module, use 9600.

Action Bar

The action bar runs across the top of the screen and contains all device controls, input tools, and settings.

Float Mode vs. Static Mode

ModeBehaviour
Float Mode (default)A rounded pill that appears when you move the mouse and auto-hides after inactivity. Keeps the video unobstructed during use.
Static ModeAlways visible at the top of the screen. Toggle in Settings → Float UI.

Auto-Hide Behaviour

  • Moving the mouse or pressing a key shows the bar.
  • Entering capture mode (clicking the video while connected) automatically hides the bar.
  • Pressing Escape to exit capture mode automatically shows the bar again.
  • Starting a QR or OCR scan hides the bar for the duration of the scan.

Resolution & Frame Rate

KitBash KVM can discover and test which resolution/FPS combinations your capture card actually supports.

  1. Start the video stream.
  2. Open Settings → Video tab.
  3. Click Recheck Video Settings — the app tests every common resolution and frame rate and lists only confirmed-working combinations.
  4. Select a combination from the Resolution & FPS dropdown.
  5. Click Apply Resolution & Frame Rate Settings.
ℹ
Tested combinations are cached per device so rechecking is only needed once, or when you change hardware.

KVM Input (Keyboard & Mouse)

Connecting

  1. Select the serial port for your adapter from the Serial Port dropdown.
  2. Choose the correct Baud Rate:
Baud RateDevice
9600Standard CH9329 module (default firmware)
57600Sipeed NanoKVM USB (default firmware)
115200Modified CH9329 firmware
  1. Click Connect.

Keyboard Capture

Once connected, click anywhere on the video to enter capture mode. All keystrokes are forwarded to the target machine.

  • Press Escape to exit capture — the action bar reappears automatically.
  • Full modifier key support: Ctrl Shift Alt Win/Cmd
💡
Keyboard Compatible Mode: Enable in Settings if keystrokes behave incorrectly on Linux or older systems. Uses an alternate HID report format.

Mouse Modes

Set in Settings → Settings tab → Cursor Mode.

Absolute Mode (default)

Mouse position maps directly to coordinates on the target screen. A crosshair cursor marks the active area.

  • Absolute Mouse Area Width / Height: Configure what percentage of the video area maps to the target screen (0–100%). Useful when the target resolution doesn't fill the entire capture area.

Relative Mode

Uses pointer lock — movements are captured as deltas and forwarded directly. Recommended for Linux guests where absolute positioning can be unreliable.

Auto Capture Mouse

When enabled (default), clicking the video immediately enters capture mode. When disabled, a confirmation dialog appears first.

Send Text

Sends a string of plain text to the target machine as a series of keystrokes.

  1. Click Send Text in the action bar.
  2. Type or paste your text in the dialog.
  3. Press OK or Ctrl+Enter to send.
  • Characters are sent one at a time with a small inter-key delay.
  • Only ASCII characters are supported. Unsupported characters trigger a warning notification.
  • Uppercase letters are handled automatically using Shift.
💡
For text with special keys or delays, use Send Advanced Text instead.

Send Advanced Text

Sends text with embedded command sequences for pressing special keys, modifier combinations, and timed delays — useful for automating login sequences, scripts, and repetitive tasks.

  1. Click Send Adv. Text in the action bar.
  2. Enter your text and commands using the escape sequence syntax below.
  3. Press OK or Ctrl+Enter to send.

Macros

Macros let you save frequently used advanced text sequences and run them instantly from the action bar.

Creating a Macro

  1. Open Settings → Macros tab.
  2. Click Add Macro.
  3. Enter a name (up to 30 characters) and the macro content using Advanced Text syntax.
  4. Click OK to save.

Running a Macro

Select a macro from the Select Macro dropdown in the action bar and press the run button. The macro executes immediately using the same engine as Send Advanced Text.

QR Code Scanner

Scan QR codes displayed on the target machine's screen without needing to type them manually.

  1. Click the QR Scanner button (cyan icon) in the action bar.
  2. A darkened selection overlay appears over the video stream.
  3. Drag to draw a box around the QR code — the selected area shows clearly while the rest dims.
  4. Release — the app decodes the QR code and copies the result to your clipboard.
  • A notification confirms success or indicates no code was found.
  • Press Escape to cancel without scanning.
  • The hint text fades out after 2 seconds so it doesn't obscure the image.
💡
Auto-Open QR Links: Enable in Settings to automatically open scanned URLs in a new browser tab.

OCR Text Extraction

Extract text visible on the target machine's screen using optical character recognition (Tesseract.js).

  1. Click the OCR button (orange icon) in the action bar.
  2. A darkened selection overlay appears over the video stream.
  3. Drag to draw a box around the text — the selected area shows clearly while the rest dims.
  4. Release — the app runs OCR and copies the extracted text to your clipboard.
  • A notification confirms success or warns if no text was found.
  • Press Escape to cancel without scanning.
  • Processing may take a few seconds for large areas.
💡
Auto-Open OCR URLs: Enable in Settings to automatically open any URLs detected in the extracted text.
ℹ
OCR works best on clear, high-contrast text at a reasonable font size. Increase the video resolution for better accuracy.
